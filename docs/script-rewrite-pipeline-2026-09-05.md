# Переписывание референса с продуктом

## Поведение

- Все новые сценарии используют один writer/review pipeline. Старый флаг `OMNI_LLM_PROMPT_CHAIN=false` больше не включает альтернативную генерацию со своей логикой повторов.
- Автор сохраняет исходную историю, ответ на хук и названия из подборки; заменяет чужую рекламу и добавляет подтверждённое действие нашего продукта.
- Автор возвращает речевые группы. Код рассчитывает длительности 4/6/8/10 секунд с прежним ориентиром четыре слова на две секунды. Ошибочная арифметика модели не требует повторной генерации текста.
- Если группы можно исправить объединением законченных предложений, код делает это без изменения слов. Если текст действительно не помещается, автор получает одну попытку исправления.
- Режиссёр и сохранённый timed plan получают один проверенный речевой план. Дальнейшие визуальные проверки и ограничения физики сохраняются.
- Смысловая проверка возвращает конкретные дефекты с цитатами. Редакционные предпочтения, отсутствие переходной цитаты и отдельного вывода после CTA не блокируют текст сами по себе.
- Название продукта проверяется по всей последовательности слов с ограниченным допуском русского склонения. Проверка не принимает совпадение одного общего слова за название.
- В исправление передаются контролируемые инструкции по дефектам, а не свободные советы модели. Цитаты и исходное сообщение остаются диагностикой.
- После неуспешного исправления текст сохраняется как draft с причиной. Платные подготовка, раскадровка и отправка видео блокируются до успешной проверки. Пустой ответ остаётся failed.
- В карточке появился редактор: `Сохранить и проверить` проверяет точный пользовательский текст, не переписывая его. Старые визуальные планы сбрасываются; тексты и проверки попыток сохраняются. Изменение сценария, уже связанного с роликом, запрещено.

## Инфраструктурные причины

- Перед запросом анализа проверяется размер исходного видео. Для источника больше наблюдавшегося лимита 15 МиБ создаётся отдельная уменьшенная копия; исходник сохраняется. Неудачная подготовка не переключается на заведомо большой оригинал.
- Явные ошибки доступа/баланса провайдера останавливают подбор, не расходуя следующие референсы. Источник остаётся доступным для повторного запуска после восстановления аккаунта.
- Готовое видео можно повторно доставить на Яндекс Диск без повторной генерации и склейки. Проверяются существующий файл, размер и MD5; другой файл не перезаписывается. После неопределённого исхода загрузки сначала проверяется её результат.
- Ошибка доставки сохраняет этап и целевой путь. У исторических ошибок без пути папка восстанавливается по текущим настройкам, имя — из сохранённого S3 URL; старое переименование папки восстановить невозможно.

## Проверки

- Production build и TypeScript прошли.
- ESLint изменённых исходников прошёл; исходных файлов длиннее 500 строк не добавлено.
- 18 целевых executable regression scripts прошли: сценарий, смысловые дефекты, речь, сохранение черновика, запрет платной генерации, подготовка, анализ, физика и доставка.
- Дополнительный compiled TypeScript suite: 11/11, включая склонение страны, отрицание свойства продукта и отсутствие свободного совета модели в промпте исправления.
- Независимый Antigravity/Gemini review недоступен: первый вызов не получил разрешение headless CLI на чтение файлов, второй получил код прямо в запросе, но завершился по таймауту. Он не включён в список пройденных проверок.
- Проверка размера видео использовала реальный локальный ffmpeg; сеть и S3 замоканы. Проверка Яндекс Диска использовала замоканную сеть, реальные доставки не выполнялись.
- Все 181 сохранённый сценарий проверены локально на разбиение речи: 119 выполнимых, 55 требуют изменения текста, 7 пустых. Это историческая выборка разных версий; не показатель успеха новой генерации.
- Реальные текстовые прогоны на Refs 953, 956, 965, 969 выявили и помогли устранить лишние отказы из-за подсчёта секунд, неточных позитивных цитат и разбиения короткого CTA. Для всех четырёх получены успешные результаты в ходе итераций. Это небольшой smoke test, не гарантия качества всех будущих сценариев.
- В 54 изменённых исходниках и тестах не найдено распространённых шаблонов токенов/закрытых ключей. Полноценный Gitleaks в локальном PATH недоступен; данная проверка не является его заменой.

Повторяемые команды: `node scripts/test_omni_creative_preflight.mjs`, `node scripts/test_omni_product_integration_prompts.mjs`, `node scripts/test_omni_generated_script_draft.mjs`, `node scripts/test_omni_director_video_input.mjs`, `node scripts/test_omni_yandex_delivery.mjs`, затем `cd ui && npm run build`.

## Развёртывание и ограничения

Изменения ещё не развёрнуты. При деплое требуется обновить не только web, но и отдельный legacy final-video-scheduler: в репозитории он уже выведен из работы, а старый контейнер продолжает исполнять старый SQL.

Пополнение баланса, изменение учётных данных провайдера и восстановление внешнего доступа не выполнялись. Причина конкретных 403 по доступному ответу не установлена.

Смысл остаётся задачей LLM: проверка цитат устраняет часть противоречий, но не доказывает истинность произвольной перефразировки. Поддерживаемая модель может ошибиться; неустранимый дефект оставляет редактируемый черновик до платного этапа. Фактическая скорость произношения и физика готового видео в этой работе не измерялись.

Локальные материалы в игнорируемом `tmp/`: `rewrite-regression-results.json`, `history-speech-preflight-current.json`, `rewrite-live-text-trial*.json`, `rewrite-review-trace.json`. Они не входят в Git.
